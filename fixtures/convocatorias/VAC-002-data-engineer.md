## 1. Descripción del puesto

El área de Datos y Analítica busca una persona que se incorpore al equipo
responsable de la plataforma de datos de la compañía: ingesta, transformación,
calidad y disponibilidad de la información que consumen los equipos de negocio.

## 2. Funciones principales

1. Diseñar, construir y mantener pipelines de datos por lotes y en tiempo real.
2. Modelar datos para su explotación analítica.
3. Implementar controles de calidad y validaciones sobre los conjuntos de datos.
4. Optimizar consultas y procesos de coste elevado.
5. Documentar el linaje de los datos y sus transformaciones.
6. Colaborar con los equipos de analítica y de producto.

## 3. Requisitos obligatorios

| # | Requisito | Justificación |
|---|---|---|
| R1 | Mínimo **3 años** de experiencia en ingeniería de datos | El puesto requiere autonomía en el diseño de pipelines |
| R2 | **Python** y **SQL** acreditados | Herramientas centrales del stack de datos |
| R3 | Experiencia con orquestadores de flujos (**Airflow**, **Dagster**, **Prefect** o equivalente) | Toda la plataforma se orquesta con estas herramientas |
| R4 | Experiencia con almacenes de datos analíticos o procesamiento distribuido (**Spark**, **BigQuery**, **Snowflake**, **Redshift**) | Volumen de datos que excede el procesamiento en una sola máquina |
| R5 | Inglés nivel **B1** o superior | Documentación técnica de las herramientas utilizadas |

## 4. Requisitos valorables

- dbt para transformación y modelado.
- Infraestructura como código (Terraform).
- Kafka u otros sistemas de streaming.
- Experiencia en gobierno de datos y catalogación.
- Conocimientos de visualización (Power BI, Tableau, Looker).
- Certificaciones de proveedores de nube.

## 8. Aviso sobre el tratamiento de datos y el uso de IA

Aplican las mismas garantías descritas en el resto de convocatorias de la
